The task
Context: Our customers browse a catalogue of a few hundred products and need to find the right one fast.

The task: Build a single page that lists products from the JSON file below and lets the user:
- search by name,
- filter by category and price range,
- sort by price or rating,
- see an empty state when nothing matches.
It must work well on a phone and on a laptop.

Resources: Use https://dummyjson.com/products as the data source. Any framework (or none) is fine.

How we'll evaluate: see the scoring guide. We care more about clean, readable code and a polished experience than about the number of features.
